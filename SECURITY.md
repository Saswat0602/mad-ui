# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.16.x  | :white_check_mark: |
| < 2.16  | :x:                |

## Reporting a Vulnerability

We take the security of Mad UI seriously. If you believe you have discovered a security vulnerability in this project, please report it privately.

**Please do not report vulnerabilities via public GitHub issues, discussions, or social media.**

### How to report:
1. Use GitHub Private Vulnerability Reporting on the [Mad UI Security tab](https://github.com/Saswat0602/mad-ui/security).
2. Alternatively, email the maintainer at `saswatranjan0602@gmail.com` with the subject line:  
   `[SECURITY] Vulnerability report in mad-ui-components`.

### What to include in your report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof of concept (PoC).
- Affected version(s) and environment (Node, Next.js, React version, browser).

### Response SLA:
- **Acknowledgment:** Within 72 hours of receiving your report.
- **Triage & Status Update:** Within 7 business days.
- **Remediation & Patch:** Released as soon as a verified fix is tested and verified.

Credit will be gladly given to the finder upon disclosure, provided the disclosure was coordinated responsibly.
